## Testing Standards Established

### Architecture: Page Objects + Steps + Assertions (BDD)
```
Pages       → Encapsulate selectors & low-level actions
Steps       → Business-level scenarios (Given-When-Then)
Assertions  → Domain-specific expectations
Fixtures    → Pre-configured test environment
```

### Selector Convention
```javascript
// ✅ REQUIRED
page.getByTestId('btn-add-to-cart')

// ❌ NOT ALLOWED
page.locator('.btn-primary')
page.getByRole('button', { name: 'Add' })
```

### Test Tags
- `@smoke` - Quick smoke tests (< 5s)
- `@critical` - Critical user flows
- `@ui` - Frontend/UI tests
- `@api` - API endpoint tests
- `@admin` - Admin-only tests
- `@boundary` - Edge cases
- `@validation` - Input validation
